# Endereço de entrega escolhido sem Identificação

O cliente precisa saber se entregamos no endereço dele antes de se comprometer com qualquer cadastro. Por isso o Endereço de entrega pode ser escolhido no cardápio sem confirmar o celular, contrariando a regra original do Checkout, em que as páginas de endereço exigiam a Identificação. Sem Identificação não há Endereços salvos: o visitante busca, confirma no mapa e informa os dados de entrega, mas só salva o endereço depois de se identificar.

## Considerações

- Rejeitado: exigir o celular antes do endereço. Protege a regra anterior, mas faz o cliente confirmar o celular só para descobrir que não atendemos a região.
- Só avisamos quando não entregamos. Um endereço atendido não gera mensagem; a Taxa de entrega aparece no Checkout.
- Identificar-se depois não troca o Endereço de entrega pelo Endereço salvo do cadastro, e o Checkout continua passando pela etapa Endereço, já com ele marcado.
- Ao Sair, o Endereço de entrega é limpo, porque pode ser a casa de alguém num computador compartilhado. O Carrinho permanece.
