# Rótulos de triagem

| Papel e rótulo | Significado |
| --- | --- |
| needs-triage | Precisa de avaliação do mantenedor |
| needs-info | Aguarda informações do solicitante |
| ready-for-agent | Especificado e pronto para execução por agente |
| ready-for-human | Requer implementação humana |
| wontfix | Não será executado |

Use esses valores na linha `Status:` dos tickets durante a triagem.
